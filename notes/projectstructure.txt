SUPABASE TABELLEN
=================
trips               Alle Reisen
teilnehmer          Reise-Teilnehmer
ausgaben            Kosten & Ausgaben
packliste           Packlisten-Items
trip_links          Links pro Reise
trip_members        Beigetretene Mitglieder
visited_countries   Besuchte Länder


WICHTIGE BEFEHLE
================
Lokal starten:      npm run dev
Änderungen pushen:  git add . → git commit -m "..." → git push
Paket installieren: npm install paketname --legacy-peer-deps
